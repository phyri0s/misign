# 0003 — GPLv3 license

- **Status**: accepted
- **Date**: 2026-09-25

## Context

The repository is public on GitHub. The project must be open to forks, modifications and contributions, while staying free software.

## Decision

GPLv3 license. Contributions are signed off under the DCO (`git commit -s`).

## Consequences

- Any derivative work must remain under the GPL and publish its source code.
- Accepted dependency licenses: MIT, BSD, Apache 2.0, LGPL, GPLv3. AGPL or otherwise incompatible libraries are excluded.
